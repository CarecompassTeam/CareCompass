# Frontend

## Responsibility

The frontend contains the user interface, pages, reusable components, hooks, utilities, and API client services.

## Structure

- `src/components/` — Reusable UI components.
- `src/pages/` — Application pages.
- `src/services/` — API communication.
- `src/hooks/` — Reusable React hooks.
- `src/utils/` — Shared frontend utilities.
- `src/App.jsx` — Main application component.

## Getting Started

Dependencies and run scripts will be documented after the frontend framework and tooling are configured.

Coordinate API expectations with the backend team and document agreed request and response formats in `docs/api.md`.
