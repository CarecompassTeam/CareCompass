# AI Module

## Responsibility

The AI module contains AI-related services, prompt definitions, retrieval functionality, and tests.

## Structure

- `src/retrieval/` — Retrieval and context preparation.
- `src/prompts/` — Prompt templates and related configuration.
- `src/services/` — AI provider integrations and orchestration.
- `tests/` — AI-related tests and evaluation cases.

## Development Guidelines

- Keep provider credentials outside source control.
- Document input and output formats.
- Test failure cases and unexpected inputs.
- Coordinate integration requirements with the backend team.

The AI provider, framework, and execution commands will be documented after the team finalizes these choices.
