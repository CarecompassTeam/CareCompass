# API Documentation

## Status

API contracts are not finalized yet. Add endpoints here as the team agrees on them.

## Endpoint Documentation Format

For each endpoint, document:

- **Method and path:** For example, `GET /api/example`
- **Purpose:** What the endpoint does.
- **Authentication:** Whether a signed-in user is required.
- **Request parameters:** Path parameters, query parameters, or request body.
- **Successful response:** Status code and response format.
- **Error responses:** Possible error status codes and messages.
- **Validation:** Required fields and constraints.
